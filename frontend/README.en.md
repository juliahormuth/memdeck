# Memdeck - Frontend

[Português](README.md) | **English** | [Deutsch](README.de.md)

Web interface of Memdeck, built with React, TypeScript and Vite. It works in desktop and mobile browsers.

## Requirements

- Node.js 22.12 or newer
- The Memdeck backend running at `http://localhost:8080`

## Running

```bash
npm install
npm run dev
```
