# Memdeck - Frontend

[Português](README.md) | [English](README.en.md) | **Deutsch**

Weboberfläche von Memdeck, entwickelt mit React, TypeScript und Vite. Sie läuft im Browser am Computer und am Smartphone.

## Voraussetzungen

- Node.js 22.12 oder neuer
- Das Memdeck-Backend läuft unter `http://localhost:8080`

## Ausführen

```bash
npm install
npm run dev
```
