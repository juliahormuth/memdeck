# Memdeck - Frontend

**Português** | [English](README.en.md) | [Deutsch](README.de.md)

Interface web do Memdeck, feita com React, TypeScript e Vite. Funciona no navegador do computador e do celular.

## Requisitos

- Node.js 22.12 ou mais recente
- Backend do Memdeck rodando em `http://localhost:8080`

## Como rodar

```bash
npm install
npm run dev
```
