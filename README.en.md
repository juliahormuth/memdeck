# Memdeck

[Português](README.md) | **English** | [Deutsch](README.de.md)

Final course project - Software Engineering postgraduate program, Pontifical Catholic University of Minas Gerais (PUC Minas).

Web platform to create and review flashcard decks with spaced repetition. It works in the browser, including on mobile.

## Repository layout

| Folder | Contents |
|---|---|
| [`backend/`](backend/README.en.md) | REST API in Java 21 and Spring Boot (Clean Architecture, organized by feature) |
| [`frontend/`](frontend/README.en.md) | Web interface in React, TypeScript and Vite (Clean Architecture, organized by feature) |

## Technologies

- **Back end:** Java 21, Spring Boot 4, Spring Data JPA, Flyway
- **Database:** PostgreSQL
- **Front end:** TypeScript, React, Vite
- **CI/CD (planned):** GitHub Actions

## Status

Under development. Documentation in progress.
