# Memdeck

[Português](README.md) | [English](README.en.md) | **Deutsch**

Abschlussarbeit – Postgraduiertenstudium Software Engineering, Päpstliche Katholische Universität von Minas Gerais (PUC Minas).

Webplattform zum Erstellen und Wiederholen von Karteikarten-Stapeln mit verteilter Wiederholung (Spaced Repetition). Sie läuft im Browser, auch auf dem Smartphone.

## Struktur des Repositorys

| Ordner | Inhalt |
|---|---|
| [`backend/`](backend/README.de.md) | REST-API in Java 21 und Spring Boot (Clean Architecture, nach Funktionalität organisiert) |
| [`frontend/`](frontend/README.de.md) | Weboberfläche in React, TypeScript und Vite (Clean Architecture, nach Funktionalität organisiert) |

## Technologien

- **Backend:** Java 21, Spring Boot 4, Spring Data JPA, Flyway
- **Datenbank:** PostgreSQL
- **Frontend:** TypeScript, React, Vite
- **CI/CD (geplant):** GitHub Actions

In Entwicklung. Die Dokumentation befindet sich im Aufbau.
