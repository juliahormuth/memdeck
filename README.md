# Memdeck

**Português** | [English](README.en.md)

Trabalho de Conclusão de Curso - Pós-graduação em Engenharia de Software, Pontifícia Universidade Católica de Minas Gerais (PUC Minas).

Plataforma web para criação e revisão de baralhos de flashcards com repetição espaçada. Pode ser usada pelo navegador, inclusive no celular.

## Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| [`backend/`](backend/README.md) | API REST em Java 21 e Spring Boot (Arquitetura Limpa, organizada por funcionalidade) |

O front-end (TypeScript, React e Vite) ainda será adicionado.

## Tecnologias

- **Back end:** Java 21, Spring Boot 4, Spring Data JPA, Flyway
- **Banco de dados:** PostgreSQL
- **Front end (planejado):** TypeScript, React, Vite
- **CI/CD (planejado):** GitHub Actions

Em desenvolvimento. Documentação em construção.
